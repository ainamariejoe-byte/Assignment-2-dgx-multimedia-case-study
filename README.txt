PROJECT OVERVIEW
----------------
This project is a responsive multimedia case-study webpage based on
Digital Government Exchange 2026 (DGX 2026).

The webpage demonstrates purposeful multimedia design through:
- meaningful event text;
- optimised responsive imagery;
- a purposeful scroll-reveal animation;
- an HTML5 video component;
- an interactive event gallery;
- user-controlled information reveal;
- keyboard-accessible controls;
- visible focus states;
- reduced-motion consideration; and
- responsive presentation for desktop, tablet and mobile devices.

MULTIMEDIA FEATURES
-------------------
1. Responsive Images
   The webpage uses HTML5 <picture>, srcset and sizes so that the browser
   can select an appropriate image according to the user's screen size.

2. Optimised Image Formats
   Responsive WebP versions are provided for important raster images,
   together with JPEG fallback files where applicable.

3. Interactive Gallery
   JavaScript allows users to filter event content by:
   - All
   - Keynotes
   - Networking
   - Activities

   This interaction helps users explore DGX content according to their
   interests rather than functioning as a purely decorative effect.

4. Purposeful Animation
   Sections use a subtle scroll-triggered reveal implemented with CSS
   transitions and JavaScript IntersectionObserver.

5. Reduced Motion
   The CSS prefers-reduced-motion media query removes unnecessary
   animation for users who request reduced motion.

6. Video
   The page includes dgx-highlight.mp4 using the HTML5 <video> element.
   Playback is user-controlled and autoplay is not forced.

7. Video Captions
   English captions are provided using dgx-captions.vtt.

8. River Cruise Information Reveal
   A native HTML button allows users to show or hide additional River
   Cruise information. The control uses aria-expanded to communicate its
   state to assistive technologies.

9. Responsive Layout
   CSS Grid and media queries adapt the gallery, event information and
   River Cruise section for smaller screens.


ACCESSIBILITY AND USER CONTROL
------------------------------
The project includes:
- meaningful alternative text for informative images;
- HTML5 video controls;
- no forced autoplay;
- WebVTT captions;
- keyboard-operable native buttons;
- ARIA state information for expandable content;
- reduced-motion support; and
- responsive layouts and images.

Keyboard users can navigate interactive elements using the Tab key and
activate native buttons using Enter or Space.

GENERATIVE-AI DECLARATION

the actual DGX 2026 event.

highlight video. The real keynote-speaker promotional image was supplied
separately and was not generated by ChatGPT for this project.


RUNNING THE WEBSITE LOCALLY
---------------------------

run index.html through Live Server.

when testing web features.
